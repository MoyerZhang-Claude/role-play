# SillyTavern 内容兼容说明（v0.3.1）

原则：药汤自己的视觉与交互优先；所有差异都会写进导入报告，不会悄悄丢内容。原始卡片数据完整保存在角色文件里，以后可原样导出。

## 角色卡

| 内容 | 支持情况 |
| --- | --- |
| PNG（`chara` / `ccv3` 文本块）、JSON | ✅ V1 / V2 / V3；同时有 V3 与 V2 数据时优先 V3 |
| 名字、描述、性格、场景、开场白、对话示例 | ✅ |
| 备选开场白 | ✅ 在第一条消息上左右切换 |
| 系统提示词、历史后指令（支持 `{{original}}`） | ✅ 可在设置中关闭 |
| 深度提示词（角色备注） | ✅ |
| 内嵌世界书（character_book） | ✅ 见下表 |
| 内嵌正则（regex_scripts） | ✅ 见下表；美化类在「药汤风格」下默认关闭，切到「卡片原样式」时自动打开 |
| 作者寄语、标签、作者、版本 | ✅ 显示在角色页 |
| 群聊专用开场白、V3 附带资源（表情图等） | ⬜ 暂不使用，报告中注明 |
| 其它插件的扩展字段 | ⬜ 原样保存，不影响聊天；导出 PNG 时原样写回 |
| 导出为 PNG 角色卡 | ✅ 同时写入 V2（`chara`）与 V3（`ccv3`）；可选把绑定的世界书并进卡内 |

## 世界书

| 功能 | 支持情况 |
| --- | --- |
| 关键词（大小写、整词匹配）、`/正则/` 关键词 | ✅ |
| 次要关键词 + 四种逻辑（含任一 / 非全部 / 全不含 / 含全部） | ✅ |
| 常驻、启用开关、插入顺序（order） | ✅ |
| 插入位置：角色定义前/后、作者备注前/后、示例对话前/后、按深度（含角色身份）、出口（`{{outlet::名}}`） | ✅ |
| 扫描深度（全局与单条）、匹配角色描述/人设/场景等额外来源 | ✅ |
| 递归扫描、阻止递归、排除递归、延迟到递归 | ✅ |
| 概率、分组（权重、优先覆盖） | ✅（分组评分按权重随机简化处理） |
| 粘滞 / 冷却 / 延迟 | ✅ 状态随对话保存 |
| 预算（占上下文百分比） | ✅ |
| 向量化匹配 | ⬜ 改按关键词匹配，报告中注明 |
| 生成类型触发、自动化 ID（STscript） | ⬜ 忽略，报告中注明 |
| 独立世界书 JSON（ST 原生格式、V2 格式） | ✅ 可导入到世界书库，绑定给一位或多位角色，或设为全局；可导出为 ST 格式 |
| 纯文本设定（.txt） | ✅ 导入为只有一条常驻条目的世界书 |
| 只对某些角色生效（characterFilter） | 🔶 暂不区分，导入时提示 |
| 条目里的 EJS 模板 | 🔶 不执行，发送前去掉模板代码 |
| 条目编辑 | ✅ 所有字段都可在药汤里编辑，并能新增 / 复制 / 删除条目 |

## 正则

| 功能 | 支持情况 |
| --- | --- |
| `/pattern/flags`、捕获组 `$1`、命名组 `$<name>`、`{{match}}` | ✅ |
| 作用范围：用户输入、AI 回复、世界书、思考内容 | ✅（快捷命令无对应功能） |
| 仅显示 / 仅发送 / 直接改写原文、编辑时是否运行 | ✅ |
| 最小 / 最大深度、修剪字符串、查找内容中的宏替换 | ✅ |
| 输出带 `<style>` / `<script>` 的美化正则 | ✅ 「卡片原样式」下按作者的 CSS 显示（脚本不运行）；「药汤风格」下默认关闭，开启后只保留结构 |
| 独立正则 JSON（单个或数组） | ✅ 可导入并添加到角色（自动去重） |

## 对话补全预设

| 内容 | 支持情况 |
| --- | --- |
| 提示词列表与顺序（`prompts` + `prompt_order`，优先取全局顺序 100001） | ✅ 开关、顺序、内容都可在药汤里调整 |
| 内置段落：主提示词、世界书前 / 后、人设、角色描述 / 性格 / 场景、对话示例、聊天记录、历史后指令、辅助提示、强化定义 | ✅ |
| 自定义提示词：相对位置、按深度插入（含角色身份） | ✅ |
| 世界书 / 场景 / 性格格式模板 | ✅ |
| 续写提示、代写提示、新对话提示、新示例提示 | ✅ |
| 温度、Top P、回复上限、上下文长度、存在 / 频率惩罚 | ✅ 导入时可选是否套用到当前接口 |
| 按生成方式发送（injection_trigger） | ✅ 正常回复 / 重写 / 续写 / 代写分别判断 |
| 禁止被角色卡覆盖（forbid_overrides） | ✅ |
| 预设自带正则（extensions.regex_scripts） | ✅ 启用预设时对所有角色生效；界面美化类只在「卡片原样式」的角色里生效；可逐条开关 |
| 变量宏（setvar / getvar 等） | ✅ 按预设顺序依次计算 |
| EJS 模板（`<% %>`，需要 ST-Prompt-Template 扩展） | 🔶 不执行：发送前去掉模板代码、保留文字，条件分支不判断 |
| 酒馆助手脚本（extensions.tavern_helper）、SPreset 等扩展数据 | ⬜ 不运行，导入报告中列出 |
| 预填充（assistant prefill）、合并系统消息、名字前缀、偏置、思考强度、联网 / 图像 / 工具相关设置、Top K / Min P 等非 OpenAI 参数 | ⬜ 不使用，导入报告中逐项注明 |

## 显示

- Markdown：宽松的 `*动作*` / `**加粗**`（比标准 Markdown 更适合中文）、引用、列表、代码块、表格、分隔线。
- 卡片自定义标签（如 `<StatusBlock>`、`<Weather>`）：短内容渲染成字段网格，长内容渲染成带标签名的段落框；`<details>` 折叠；`<think>` 渲染为「思绪」。
- 被移除：`<style>` `<script>` `<iframe>` 表单、内联样式（文字颜色除外，会自动加深）、外部图片（显示为占位）。
- HTML 注释不显示，但会发给 AI。

### 卡片原样式（角色页 → 正则与显示）

- 带样式的消息（含 `<style>`、`style=`、`class=`）放进一块独立的深色底板，按卡片作者的 CSS 显示；`html` / `body` / `:root` 选择器会改指向这块底板。
- 样式只作用于这块底板，不会改变药汤的界面；`position: fixed` 之类也被限制在底板内。
- 不运行脚本；不加载外部图片、网络字体、`@import`；表单不能提交（单选 / 复选框保留，纯 CSS 的标签页可以用）。
- 正在生成的回复先按药汤风格书写，写完后换成原样式；不带样式的消息仍按药汤风格显示。
- 依赖脚本的前端界面正则（替换内容里有 `<script>`，常见于 ```html 包着的整页 HTML）不用于显示，被它替换的原文照常显示；没被处理的自定义标签里的文字保留换行。

## 暂不支持

- SillyTavern 主题（UI 主题文件）、插件 / 扩展（如 JS-Slash-Runner）、STscript、EJS 模板、群聊。
- 文本补全（非对话补全）预设、指令模板、上下文模板。

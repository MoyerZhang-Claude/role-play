# 构建与发布

源码位于 `app/`。在 Windows x64 上安装 Node.js 24 后运行 `npm ci`、`npm run typecheck`、`npm test`、`npm run dist -- --publish never`。

公开版本不需要任何开发者的 API 密钥，不在构建时调用模型接口。私人素材库、运行数据与历史安装包不参与构建。

工作流只在版本不存在时创建 Release：先以草稿上传安装包、blockmap 和 SHA-256，再公开该 Release。重跑已发布版本会跳过发布，不覆盖附件。若上传中断留下草稿，应在 GitHub 中检查草稿后再处理。

更新版本时同步修改 `app/package.json` 与 `app/package-lock.json`，补充变更记录；推送到 `main` 后检查 Actions 与 Release 附件。也可手动运行工作流。

安装包默认未进行 Authenticode 签名。SHA-256 仅用于校验下载内容是否与发布附件一致。

## 开源整理说明

- 原始工作目录保持不变；开源发布使用独立副本。
- 未发布私人素材库、包含素材的截图、个人环境记录和原始任务书。
- 依赖私人素材的测试替换为人工构造的角色卡、世界书与正则测试。
- 增加 MIT 许可证，保留随包分发的库与字体许可证。
- 不发布旧的构建输出或现有安装包，以干净源码重新构建。
- 运行时业务代码保持原样。

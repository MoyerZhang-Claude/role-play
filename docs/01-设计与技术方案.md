# 「药汤」设计与技术方案

> 本文记录已经确定的整体方向。需求变化时同步更新。最后更新：2026-10-28（第一阶段开工）

## 1. 一句话定位

一本会回应你的「药方手札」：羊皮纸、铁胆墨水、朱砂印、像素印章与魔法阵。打开它，像翻开一本被施了魔法的旧书。

## 2. 视觉方向

### 2.1 核心意象

| 意象 | 用在哪里 |
| --- | --- |
| **墨滴晕开** | 统一的交互母题：开场的第一滴墨、每次点击的墨点涟漪、重要页面切换的墨染过渡、流式文字的「墨迹渗入」 |
| **魔法阵** | 开场主体、加载/生成中的小法阵、拖入文件时的召唤阵、空状态插图 |
| **羊皮纸 + 铁胆墨** | 默认主题的底色与正文色；代码程序化生成纸张纹理（纤维、斑渍、边缘焦黄），不用图片素材 |
| **朱砂 / 金箔** | 强调色：角色名、印章、选中态用朱砂；魔法光效用金箔色 |
| **像素印章** | 「像素」元素的落点：所有图标都是 16×16 的像素画，像木刻印章一样以墨色盖在纸上；药汤印章是像素化的篆印 |

古典（手稿装饰、衬线字）＋ 幻想（法阵、符文）＋ 像素（图标与印章）分工明确，不堆在同一处。

### 2.2 色彩（默认主题「羊皮纸」）

- 纸：`#efe3c8` 主色，`#f6eddb` 亮纸，`#e2d1ad` 深纸，`#c9b088` 焦边
- 墨：`#2b2118` 铁胆墨（正文），`#4a3b2c` 淡墨，`#7a6550` 枯墨（次要文字）
- 朱砂 `#a8322a`（角色名、印章、危险操作）
- 金箔 `#b8892f` / 光 `#ffd98a`（魔法光效、悬停辉光）
- 靛墨 `#27345a`（用户的发言 —— 「你用的是另一支笔」）
- 书脊：深棕皮革 `#3a2618` 配烫金图标（只占左侧窄条，不让整体变暗）

### 2.3 字体（全部开源可商用，随安装包分发）

| 用途 | 字体 |
| --- | --- |
| 正文 / 界面 | 霞鹜文楷 屏幕阅读版（LXGW WenKai Screen），可切换为思源宋体或系统字体 |
| 大标题 | 马善政毛笔楷书（Ma Shan Zheng） |
| 英文装饰 | Cinzel（罗马碑刻大写）、IM Fell English（旧印刷体） |
| 像素小字 | Silkscreen（数字、角标） |

### 2.4 布局

```
┌──────────────────────────────────────────────────────┐
│ ◈ 药汤   书斋 › 示例角色 › 第3卷          ─  ▢  ✕  │ ← 自绘标题栏（可拖动）
├────┬─────────────────────────────────────────────────┤
│ 书 │                                                 │
│ 脊 │           主页面（书斋 / 角色 / 对话 / 设置）     │
│ 导 │                                                 │
│ 航 │                                                 │
└────┴─────────────────────────────────────────────────┘
```

- **书斋**（首页）：继续上次的对话 + 角色卷宗网格 + 新建/导入。
- **角色页**：立绘、简介、世界书/正则概况、导入说明、该角色的所有对话。
- **对话页**：居中阅读栏（宽度可调），角色发言用铁胆墨、用户发言用靛墨；左侧可收起的对话列表，右侧可收起的角色/世界书面板。
- **设置**：像书的目录一样的左侧分栏。

### 2.5 主题架构

- 主题 = 一份 `ThemeDefinition`：颜色令牌、字体、纸张纹理生成参数、装饰元素集合、光效颜色。
- 组件只引用 CSS 变量（`var(--c-ink)` 等）和主题提供的装饰组件，不直接写死羊皮纸。
- 纹理由代码按参数生成，换主题即重新生成。
- 当前只实现「羊皮纸」一个主题，但切换通路完整。

## 3. 动画与交互

### 3.1 统一手感

- **按下即反馈**：在 `pointerdown` 而不是 `click` 时触发墨点涟漪和音效，零等待。
- 按钮：按下微缩 0.96 + 弹回；悬停时墨色从光标处晕染。
- 页面切换：新页面「墨迹沉淀」（淡入 + 轻微上浮 + 模糊变清晰，约 380ms）。（进入对话等大切换的墨染过渡留到第二阶段。）
- 流式文字：新到的字以「墨渗入纸」的方式出现（淡入 + 去模糊），并做匀速化处理，避免一顿一顿的。
- 所有动画只用 transform / opacity / 着色器，保证 240Hz 下不掉帧；特效层空闲时停止渲染。

### 3.2 开场动画（≤ 6 秒，纯代码实时绘制）

「墨落成阵，汤成一滴」，约 5.6 秒。**全程不出现文字**：「药汤」是被表现出来的，而不是写出来的（v0.2 按反馈修改）。

1. 0.0–0.5s 烛光从黑暗中亮起，照出羊皮纸，浮尘飘动。
2. 0.5–1.1s 一滴墨从上方落下，溅起墨珠，在纸上沿纤维晕开。
3. 1.1–2.7s 墨迹自己快速画出魔法阵：外环、原创符文带、内环、星形连线一笔接一笔写出，每组符文对应一个琴音。随后四周画出星盘弧、两片星图，四个角上的卫星小阵按顺时针依次画出——里面是四味「药材」：本草、月与星、晶石、火焰，用虚线连向主阵。（v0.3 按反馈：不再整体突然出现）
4. 2.6–3.4s 金光沿线条奔走点亮法阵与四周，阵心的墨化作青绿色的药汤，蒸汽与火星升起。
5. 3.0–4.1s 四味药材依次化作光点，沿弧线飞入阵心；每落入一味，药汤泛起一圈涟漪、响起一个音，颜色一步步熬成熔金。
6. 4.35–4.85s 金汤里跃起一滴，落回阵心。
7. 4.85–5.6s 落下的一瞬，光环从阵心扩散，揭开纸页露出书斋——与开头的那滴墨首尾呼应。

- 技术：WebGL2 着色器（纸张、墨渗、药汤、辉光、金滴）+ Canvas2D（法阵笔画，写完的笔画缓存成图层，只旋转不重画；时间回退时清空缓存，保证预热之后仍是一笔笔画出）+ 确定性 GPU 粒子（浮尘、蒸汽、火星、药材光尾）。
- 性能：实测全程 240 帧（只有启动瞬间、画面还是黑的那一帧会慢）。
- 双击左键或 Esc 跳过（不显示任何提示）。每次启动都播。可在设置里彻底关闭，关闭后启动只保留约 0.5 秒淡入。
- 音乐与音效全部 Web Audio 实时合成，与画面按时间轴同步。

## 4. 声音

- 全部代码合成（Web Audio），不用音频文件。
- 点击音：柔和的木质「嗒」+ 纸面轻擦，低通滤波，避免刺耳；每次轻微随机音高，减少疲劳。
- 其它：翻页、发送（羽毛笔 + 落印）、回复完成（轻铃）、开关、错误。
- 背景音乐：生成式环境乐 —— D 多利亚调式的柔和长音垫底，拨弦（Karplus-Strong 合成的竖琴/鲁特琴音色）即兴旋律，偶尔一点壁炉噼啪声。永不完全重复。
- 音效、背景音乐分别开关和调音量，设置持久保存。默认都开启。

## 5. 技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 外壳 | **Electron 44**（稳定版线） | 自带 Chromium，WebGL2/Web Audio 表现稳定，跟随屏幕 240Hz 刷新；不需要 Rust 环境；安装包大小不限 |
| 构建 | electron-vite 5 + Vite 7 + TypeScript | 主进程 / 预加载 / 页面统一构建，开发时热更新 |
| 界面 | React 19 + zustand | 熟悉、稳定；状态管理轻 |
| 图形 | 原生 WebGL2 + Canvas2D，自写小型封装 | 视觉元素全部原创绘制，完全可控 |
| 文本渲染 | markdown-it + DOMPurify + 自定义标签渲染 | 支持角色卡常见的 Markdown 与状态栏标签，同时过滤脚本和外部样式 |
| 打包 | electron-builder → NSIS 安装包 | 按用户安装、无需管理员权限，可选安装目录 |
| 测试 | Vitest（逻辑单测）+ Playwright 驱动 Electron（截图与交互验证） | |

**可复用性（为将来安卓留路，但不受其限制）**：角色卡解析、世界书引擎、正则引擎、提示词组装、数据结构全部放在 `src/shared/`，是不依赖 Electron/DOM 的纯 TypeScript。界面不考虑共用。

## 6. 数据与存档

### 6.1 安装与数据目录

- 安装包：按当前用户安装（不需要管理员），默认目录 `%LOCALAPPDATA%\Programs\药汤`，安装时可改到任意位置（例如 `D:\药汤`）。
- 数据目录：**程序目录下的 `data\` 文件夹**，程序与数据放在一起。连 Chromium 自身的缓存也放进 `data\runtime\`，不往 AppData 里乱放东西。
- 升级 / 卸载：定制安装脚本，**保留 `data\` 不删**。卸载后数据仍在原处，可手动删除或拷走。
- 取舍：如果安装到 `C:\Program Files` 这类需要管理员权限的位置，程序无法写入 `data\`，会自动改用 `%APPDATA%\药汤\data` 并在设置中提示。所以安装时请选普通目录。

### 6.2 文件布局

```
data/
  settings.json            设置（不含密钥）
  secrets.json             API 密钥（Windows DPAPI 加密，只能在本机本用户解密）
  characters/<id>/         角色：character.json + avatar.png（含内嵌世界书、正则、原始卡片数据）
  chats/<角色id>/<对话id>.json   每个对话一个文件
  worldbooks/ presets/      世界书库里的独立世界书、导入的 SillyTavern 预设
  runtime/                 Chromium 缓存等运行时文件（可随意删除）
```

- 写入方式：先写临时文件再原子替换，异常退出不会写坏旧文件。
- 聊天自动保存：每次变动 300ms 内落盘；流式生成过程中每秒保存一次半成品，崩溃最多丢失约 1 秒的文字。

### 6.3 存档

导出一个 `.yaotang` 文件（zip）：

- **包含**：角色（含头像、内嵌世界书与正则）、全部对话、独立世界书/正则/预设、设置（外观、声音、对话参数、接口配置的地址与模型名）。
- **不包含**：API 密钥（默认不导出；以后若加「包含密钥」选项也会再三确认）、运行时缓存。
- 导入：可选择「合并」或「完全还原」；导入前自动备份当前数据（保留最近 5 份）。

## 7. SillyTavern 内容兼容

详见 [04-兼容性说明.md](04-兼容性说明.md)。原则：

1. 药汤自己的视觉与交互优先，外部内容不能改动界面、布局与图形设置。
2. 默认「药汤风格」：卡片里的 HTML 只保留安全的排版标签；`<style>`、脚本、外链全部移除；文字颜色会自动加深到在羊皮纸上看得清的程度。
3. 主要用于「界面美化」的正则（输出带 CSS 的整段 HTML）在药汤风格下默认不启用，并在导入报告中写明。
3a. 可按角色切换为「卡片原样式」：带样式的消息放进 Shadow DOM 隔离的深色底板，按作者 CSS 显示；样式只作用于底板内部，脚本不运行，外部资源被内容安全策略拦下。药汤的界面本身仍不受任何外部内容影响。
4. 导入时出具**导入报告**：哪些已启用、哪些有差异、哪些被忽略，绝不悄悄丢内容。
